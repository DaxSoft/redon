# Tailwind Config

## Purpose

Own shared Tailwind theme extension.

## Responsibilities

- Map Tailwind tokens to Redon CSS variables.

## Public API

Exports a Tailwind config object.

## Dependencies

No runtime dependencies.

## Usage

Import from apps or packages that use Tailwind.

## Design Rules

Tailwind colors should reference design-system variables.

## Testing

Verified through app builds.
